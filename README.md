# Discord Reaction Bot

Ein einfacher Discord-Bot für Rollen-Zuweisung per Reaktion.

## Features

- Reaction-Rollen über eine zentrale Nachricht
- Rollenvergabe und -entfernung bei Emoji-Add/Remove
- Einfach per `config.json` konfigurierbar
- `!ping` zum Checken, ob der Bot läuft
- `!setup_roles` zum automatischen Erstellen der Rollen-Nachricht

## Lokale Nutzung

1. Python 3.10+ installieren.
2. Repo clonen oder Ordner erstellen.
3. Abhängigkeiten installieren:

   ```bash
   pip install -r requirements.txt
